# 🎓 Dự Án CLB SmartCampus
***SmartCampus*** là ứng dụng di động **hỗ trợ sinh viên PTIT**  _tra cứu lịch học_, xem phòng trống và nhận thông báo từ nhà trường.
## ✨ Tính năng đã hoàn thành
-   Tra cứu lịch học theo mã sinh viên
    -   Giúp sinh viên xem lịch học cá nhân.
-   Xem phòng trống theo tòa nhà.
[Trang chủ CLB Lập trình](https://clblaptrinh.ptit.edu.vn/)
> Lưu ý: Dự án đang phát triển, chưa dùng cho mục đích chính thức.

## 🚀 Cài đặt dự án
```bash
git clone https://github.com/clb-lap-trinh/smartcampus.git
npm install
npm start
```
